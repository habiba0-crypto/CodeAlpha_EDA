# CodeAlpha Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Books Dataset containing information about 1,000 books.

The purpose of this project is to analyze book prices, ratings, and availability using Python.

## Dataset Information
The dataset contains 4 columns:
- Title
- Price
- Rating
- Availability

Total Records: 1,000 books.

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Dataset loading and inspection.
2. Missing values checking.
3. Duplicate records checking.
4. Descriptive statistical analysis.
5. Book rating distribution.
6. Book price distribution.
7. Relationship between book price and rating.
8. Book availability analysis.

## Key Findings
- Total books: 1,000.
- No missing values were found.
- No duplicate records were found.
- Average book price: 35.07.
- Minimum book price: 10.00.
- Maximum book price: 59.99.
- Average book rating: 2.923 out of 5.
- All 1,000 books are listed as In stock.

## Conclusion
The dataset was clean and contained complete information. EDA helped identify patterns in book prices, ratings, and availability through statistical analysis and visualizations.

## Project Files
- `CodeAlpha_Task2_EDA.ipynb` – Jupyter Notebook containing the analysis and visualizations.
- `CodeAlpha_WebScraping_Cleaned.csv` – Cleaned dataset used for analysis.
